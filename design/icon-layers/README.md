# PageStash icon layers

Generated by `swift scripts/draw-icon.swift <dir>`. Copy its output into place:

| File | Destination |
| --- | --- |
| `AppIcon.png`, `AppIcon-Dark.png`, `AppIcon-Tinted.png` | `ios/OfflineReader/Assets.xcassets/AppIcon.appiconset/` |
| `BrandMark.png` | `ios/OfflineReader/Assets.xcassets/BrandMark.imageset/` |
| `Layer-Pages.png`, `Layer-Sleeve.png` | `design/icon-layers/` |

Then run `swift scripts/check-icon.swift` on each `AppIcon*.png`.

For an Icon Composer (`.icon`) version, use a terracotta `#C74D26` fill with `Layer-Pages.png`
behind `Layer-Sleeve.png`. The project keeps the asset-catalog icon while CI builds with Xcode 16.4,
which cannot compile `.icon` files.
